# axmg — Дорожная карта (Roadmap)

**Цель:** Развитие `axmg` как универсального, высокопроизводительного локального движка памяти на базе Merkle DAG с интеграцией через Model Context Protocol (MCP) для локальных LLM и агентных систем (OpenClaw).

---

## 🎯 Фаза 1. Глубокая переработка Ядра (`axmg-kernel`) [Завершена]

- [x] **1.1. Потоковое распознавание (`StreamingRecognizer`)** — $O(N)$ свёртка чанков байт в реальном времени с сохранением детерминизма Merkle DAG.
- [x] **1.2. Ассоциативное вспоминание (`recall`)** — субграфный обход `Query -> PPMI-соседи -> Score -> Декодирование` и интеграция в MCP.
- [x] **1.3. Онлайн-вычисление Surprise** — расчет $S_{\text{static}}$ и $S_{\text{growth}}$ в горячем цикле `turn` без клонирования `Store`.
- [x] **1.4. Неблокирующий доступ к фокусу (`FocusSet`)** — lock-free RCU-снапшоты активных концептов ($K=3$, `Death`) и транзакционный сброс в `redb`.
- [x] **1.5. Рефакторинг и очистка** — удаление модулей III септенера (`devil.rs`, `tower.rs`, `world.rs` и др.) в архив `arch/`.

---

## 🔌 Фаза 2. Сервер памяти `axmg-memory-mcp` [Завершена]

- [x] **2.1. Реализация MCP JSON-RPC сервера (stdio транспорт)**
  - Создание легковесного бинарника `axmg-mcp` поверх ядра `shelf`.
  - Поддержка стандартного протокола Model Context Protocol (спецификация 2024-11-05 / актуальная версия).

- [x] **2.2. Реализация MCP-ресурсов (Resources)**
  - `memory://focused` — список активных концептов и ассоциаций текущего фокуса.
  - `memory://stats` — статистика хранилища: количество токенов, обороты Колеса, коэффициент компрессии.
  - `memory://timeline` — хронологический срез недавних событий.

- [x] **2.3. Реализация MCP-инструментов (Tools)**
  - `remember(text, context_tag)` — запись события в память с возвратом Surprise-скора.
  - `recall(query, limit)` — поиск релевантных воспоминаний и ассоциаций.
  - `check_surprise(hypothesis)` — быстрая оценка согласованности гипотезы с накопленным опытом.
