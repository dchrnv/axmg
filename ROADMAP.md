# axmg — Дорожная карта (Roadmap)

**Цель:** Развитие `axmg` как универсального, высокопроизводительного локального движка памяти на базе Merkle DAG с интеграцией через Model Context Protocol (MCP) для локальных LLM и агентных систем (OpenClaw).

---

## 🧬 Фаза 5. Суверенный Когнитивный Контур (Headless + Говорилка + Родная Rust-модель) [В планах]

- [ ] **5.1. Связка с «Бонсай без головы» (Headless Feature & Decision Model)**
  - Использование высокопараметрической не-генеративной модели с древовидной/разреженной маршрутизацией (бонсай / sparse routing) для мгновенного извлечения латентных состояний без авторегрессионного тормоза (~200x прирост скорости).
  - Проекция скрытых векторов в дискретные структуры Колеса `axmg`.

- [ ] **5.2. Реализация двух вариантов «Говорилки» (Исполнительной Головы)**
  - **Вариант А (Текстовая микро-говорилка / Surface Vocalizer):**
    - Компактная легковесная модель (0.5B – 1.5B параметров) исключительно для быстрого грамматического развёртывания фактов из `axmg` в связный текст со скоростью 150–300 токенов/сек.
  - **Вариант Б (Прямая голосовая голова / Direct Voice & Acoustic Streamer):**
    - Потоковый синтез живой речи (TTS / акустические токены, 80M – 300M параметров) с ультранизкой сквозной задержкой отклика (**100–150 мс**), минуя этап посимвольного вывода текста на экран.

- [ ] **5.3. Родная обучаемая модель на Rust (Непрерывное взросление интеллекта)**
  - Разработка специализированной архитектуры на Rust (GNN на Merkle DAG / State Space Model / BitNet), тесно спаянной с SoA-ареной `Store`.
  - Непрерывная дистилляция опыта внешнего headless-мыслителя в веса родной модели с постепенным переходом на полную цифровую суверенность.

- [ ] **5.4. Векторная 4-параметрическая система поощрения (Нервная система)**
  - Мультикритериальный бинарный сигнал обратной связи для обучения и вытеснения:
    1. $R_{\text{truth}}$ — техническая истинность (успех компиляции, код возврата 0, отсутствие паник и сбоев);
    2. $R_{\text{user}}$ — одобрение и подтверждение наблюдателя (человека);
    3. $R_{\text{parsimony}}$ — компактность графа и рост компрессии по Оккаму (инвариант `axmg`);
    4. $R_{\text{novelty}}$ — продуктивная новизна и баланс Surprise (`NOVEL_GROWTH` против заучивания и шума).
